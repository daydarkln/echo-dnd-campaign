# Интеграция системы персонажей с группами

## Обзор

Система персонажей теперь полностью интегрирована с системой групп. Пользователи могут:

1. **Выбирать существующих персонажей** при добавлении в группу
2. **Создавать новых персонажей** прямо при добавлении в группу
3. **Синхронизировать данные** между системой персонажей и группами
4. **Видеть информацию о группах** на странице персонажей

## Новые компоненты

### CharacterSelector

**Расположение**: `src/components/CharacterSelector.tsx`

Модальное окно для выбора или создания персонажа при добавлении в группу.

**Возможности**:
- Две вкладки: "Выбрать существующего" и "Создать нового"
- Показывает всех доступных персонажей из системы персонажей
- Отображает статус листа персонажа (создан/только базовая информация)
- Форма для быстрого создания нового персонажа

**Props**:
```typescript
interface CharacterSelectorProps {
  visible: boolean;
  onClose: () => void;
  onSelectCharacter: (character: { id: string; name: string; class?: string; level?: number }) => void;
  onCreateCharacter: (character: { name: string; class?: string; level?: number }) => void;
  title?: string;
}
```

### useCharacterGroupSync

**Расположение**: `src/hooks/useCharacterGroupSync.ts`

Хук для управления связями между персонажами из основной системы и персонажами в группах.

**Основные функции**:
- `saveMapping()` - сохранение связи между персонажами
- `syncCharacterToGroups()` - синхронизация данных персонажа во все группы
- `getCharacterGroupInfo()` - получение информации о группах, где находится персонаж
- `removeCharacterFromAllGroups()` - удаление персонажа из всех групп

## Маппинги и синхронизация

### Структура маппинга

Связи между персонажами сохраняются в `localStorage` под ключом `character-group-mappings`:

```typescript
interface CharacterGroupMapping {
  originalCharacterId: string;   // ID в системе персонажей
  groupId: string;              // ID группы
  groupCharacterId: string;     // ID персонажа в группе
}
```

### Процесс синхронизации

1. **Автоматическая синхронизация**: При изменении персонажа в основной системе
2. **Ручная синхронизация**: Кнопка "Синхронизировать" на странице персонажей
3. **Двунаправленная связь**: Изменения в группе могут быть синхронизированы обратно

### Хранение данных

- **Основная система персонажей**: `localStorage` + JSON server
- **Система групп**: `localStorage`
- **Маппинги**: `localStorage` под ключом `character-group-mappings`

## Пользовательские сценарии

### Сценарий 1: Добавление существующего персонажа в группу

1. Открыть страницу групп
2. Нажать "Добавить участника" в нужной группе
3. Выбрать вкладку "Выбрать существующего"
4. Выбрать персонажа из списка
5. Нажать "Добавить в группу"

**Результат**: Персонаж появляется в группе, создается маппинг, на странице персонажей появляется тег группы.

### Сценарий 2: Создание нового персонажа для группы

1. Открыть страницу групп
2. Нажать "Добавить участника" в нужной группе
3. Выбрать вкладку "Создать нового"
4. Заполнить имя и уровень
5. Нажать "Создать и добавить в группу"

**Результат**: Персонаж создается в основной системе И добавляется в группу, создается маппинг.

### Сценарий 3: Синхронизация изменений

1. Отредактировать персонажа на странице персонажей
2. Нажать кнопку "Синхронизировать" 
3. Проверить группы - данные персонажа обновлены

**Результат**: Изменения имени, класса и уровня применяются во всех группах, где находится персонаж.

## API

### CharacterSelector API

```typescript
// Выбор существующего персонажа
onSelectCharacter({
  id: "char-123",
  name: "Арагорн",
  class: "Следопыт",
  level: 5
});

// Создание нового персонажа
onCreateCharacter({
  name: "Гэндальф",
  level: 10
});
```

### useCharacterGroupSync API

```typescript
const {
  syncCharacterToGroups,      // Синхронизация персонажа во все группы
  getCharacterGroupInfo,      // Получение информации о группах
  saveMapping,                // Сохранение связи
  removeCharacterFromAllGroups // Удаление из всех групп
} = useCharacterGroupSync();

// Синхронизация
await syncCharacterToGroups("char-123");

// Получение групп персонажа
const groups = getCharacterGroupInfo("char-123");
// Возвращает: [{ groupId, groupName, groupCharacterId, characterInGroup }]
```

## Технические детали

### Совместимость

- Существующие персонажи в группах остаются без изменений
- Новая система работает параллельно со старой
- Маппинги создаются только для новых персонажей

### Производительность

- Ленивая загрузка персонажей при открытии селектора
- Кэширование маппингов в памяти
- Асинхронная синхронизация без блокировки UI

### Обработка ошибок

- Graceful fallback при недоступности JSON server
- Предупреждения в консоли при ошибках синхронизации
- Пользовательские уведомления об успехе/ошибке операций

## Будущие улучшения
