# 📥 Руководство по импорту существ

Система бестиария поддерживает несколько способов импорта существ с удобным предпросмотром перед окончательным добавлением.

## 🚀 Способы импорта

### 1. Загрузка JSON файла

**Как использовать:**
1. Нажмите кнопку "Импорт" в бестиарии
2. Выберите вкладку "Загрузка файла"
3. Перетащите JSON файл или нажмите для выбора
4. Просмотрите результаты парсинга
5. Используйте "Предпросмотр" для проверки данных
6. Подтвердите импорт

### 2. Прямой ввод JSON

**Как использовать:**
1. Нажмите кнопку "Импорт" в бестиарии
2. Выберите вкладку "Ввод JSON"
3. Вставьте или введите JSON данные
4. Нажмите "Парсить JSON"
5. Просмотрите результаты
6. Используйте "Предпросмотр" для проверки
7. Подтвердите импорт

## 🔍 Предпросмотр существа

Новая функция предпросмотра позволяет:

- **Просмотр всех данных** существа до импорта
- **Проверка корректности** парсинга полей
- **Валидация** черт, действий и характеристик
- **Просмотр в стиле** официального справочника D&D

### Как использовать предпросмотр:
1. После парсинга JSON нажмите "Предпросмотр" у нужного существа
2. Откроется полное представление существа
3. Проверьте все данные (характеристики, черты, действия)
4. Закройте предпросмотр и подтвердите импорт

## ⚠️ Валидация данных

Система автоматически проверяет:

- **Обязательные поля**: название, размер, тип, КД, ХП
- **Корректность характеристик**: значения от 1 до 30
- **Формат данных**: правильные типы полей
- **Целостность**: непротиворечивые данные

### Статусы валидации:
- ✅ **Зеленый** - данные корректны
- ⚠️ **Оранжевый** - есть предупреждения, но импорт возможен
- ❌ **Красный** - критические ошибки, импорт невозможен

## 🛠️ Автоматические преобразования

При импорте система автоматически:

1. **Рассчитывает** бонус мастерства по УО
2. **Определяет** опыт за существо
3. **Конвертирует** старые форматы в новый
4. **Дополняет** недостающие обязательные поля
5. **Нормализует** структуру данных

## 📊 Примеры импорта

### Быстрый импорт через текст
1. Скопируйте JSON существа из любого источника
2. Откройте импортер → "Ввод JSON"
3. Вставьте данные и нажмите "Парсить JSON"
4. Проверьте предпросмотр
5. Импортируйте

### Массовый импорт из файла
1. Подготовьте JSON файл с массивом существ
2. Откройте импортер → "Загрузка файла"
3. Выберите файл
4. Просмотрите все существа
5. Проверьте проблемные через предпросмотр
6. Импортируйте все сразу

## 🔧 Устранение проблем

### Существо не отображается после импорта
- Проверьте консоль браузера (F12)
- Убедитесь, что JSON корректен
- Используйте предпросмотр для диагностики

### Отсутствуют черты или действия
- Проверьте структуру JSON
- Убедитесь в корректности полей `traits` и `actions`
- Используйте предпросмотр для проверки

### Ошибки валидации
- Проверьте обязательные поля
- Убедитесь в корректности типов данных
- Исправьте данные и повторите импорт
