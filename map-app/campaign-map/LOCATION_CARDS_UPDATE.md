# Обновление карточек локаций

## Что изменилось

Карточки локаций в графе стали значительно более информативными и интерактивными.

## Новые возможности карточек

### 🎨 Визуальные улучшения
- **Прямоугольные карточки** вместо простых кругов
- **Адаптивный размер**: карточки увеличиваются при наведении курсора
- **Цветовое кодирование** по типу локации:
  - 🔴 Красный - опасные места (враги, ловушки)
  - 🟢 Зелёный - безопасные места (укрытия)
  - 🟣 Фиолетовый - магические места
  - 🟠 Оранжевый - населённые места  
  - 🔵 Синий - водные объекты

### 📊 Информативные индикаторы

#### Основные индикаторы содержимого:
- **⚔️ Энкаунтеры** (красный кружок) - количество боевых встреч
- **💰 Лут** (жёлтый кружок) - количество предметов и сокровищ
- **🔍 Улики** (синий кружок) - количество зацепок для расследования

#### Дополнительные индикаторы (при ховере):
- **↑ Усилители** (красный) - факторы, увеличивающие опасность
- **↓ Ослабители** (зелёный) - факторы, снижающие опасность

### 🎯 Интерактивность

#### Обычное состояние:
- Компактная карточка с названием локации
- До 2 основных тегов
- Индикаторы содержимого

#### При наведении курсора:
- Увеличенная карточка
- Полное название локации
- До 4 тегов
- Дополнительные индикаторы усилителей/ослабителей
- Информация о количестве дополнительных тегов

#### Подсветка связей:
- При наведении на карточку подсвечиваются связанные локации
- Затемняются несвязанные элементы для лучшей видимости

## Компоненты

### LocationCard.tsx
Новый компонент для отрисовки информативных карточек локаций:
- Адаптивный размер и содержимое
- Автоматическое цветовое кодирование
- Иконки тегов
- Индикаторы содержимого

### LocationCardLegend.tsx  
Компонент легенды с объяснением всех элементов карточек:
- Складывающаяся панель с подробными объяснениями
- Цветовые образцы
- Примеры индикаторов
- Список всех поддерживаемых тегов

## Где доступно

Новые карточки используются во всех компонентах карты:
- ✅ MapGraph - основная карта кампании
- ✅ GroupedMindMap - групповая карта с трекерами
- ✅ PlayerMap - карта для игроков
- ✅ RegionFocusedMap - карта региона

## Обратная совместимость

- Узлы других типов (регионы, группы) отображаются как прежде
- Старые данные локаций полностью поддерживаются
- API остался без изменений

## Логика цветового кодирования

```typescript
// Пример определения цвета карточки
const getCardColor = (node: GraphNode): string => {
  const tags = node.data?.location?.tags || [];
  
  if (tags.some(tag => tag.includes('опасность'))) return '#ff4d4f'; // Красный
  if (tags.some(tag => tag.includes('укрытие'))) return '#52c41a';    // Зелёный
  if (tags.some(tag => tag.includes('магия'))) return '#722ed1';      // Фиолетовый
  if (tags.some(tag => tag.includes('деревня'))) return '#fa8c16';    // Оранжевый
  if (tags.some(tag => tag.includes('источник'))) return '#1890ff';   // Синий
  
  return '#40a9ff'; // По умолчанию
};
```
