# Скрипты миграции данных

## migrate-from-db-json.js

Скрипт для миграции данных из `db.json` в Strapi базу данных.

### Подготовка

1. Убедитесь что Strapi сервер запущен:
```bash
npm run develop
```

2. Убедитесь что установлены все зависимости:
```bash
npm install
```

### Использование

#### Тестовый запуск (рекомендуется)
```bash
node scripts/migrate-from-db-json.js --dry-run
```

#### Полная миграция с очисткой существующих данных
```bash
node scripts/migrate-from-db-json.js --clean
```

#### Миграция без очистки (добавляет к существующим данным)
```bash
node scripts/migrate-from-db-json.js
```

### Опции

- `--dry-run` - Тестовый режим, показывает что будет мигрировано без выполнения
- `--clean` - Очищает существующие данные перед миграцией  
- `--help` или `-h` - Показывает справку

### Что мигрируется

1. **World Areas** - Области мира из секции `areas`
2. **Locations** - Точки интереса из секции `points-of-interest`
3. **World Paths** - Пути между локациями из секции `routes`
4. **Quests** - Квесты (если присутствуют в данных)

### Структура данных

Скрипт автоматически преобразует структуру данных из формата db.json:
```json
{
  "fieldName": {
    "value": "actual_value", 
    "visibility": "visible"
  }
}
```

В формат Strapi:
```json
{
  "fieldName": {
    "value": "actual_value",
    "visibility": "visible"
  }
}
```

### Обработка ошибок

Скрипт продолжает работу даже при ошибках отдельных записей и выводит подробную статистику в конце.

### Требования

- Node.js 18+
- Запущенный Strapi сервер на `http://localhost:1337`
- Файл `db.json` в корне проекта

### Устранение проблем

#### Ошибка "fetch is not defined"
Убедитесь что используете Node.js 18+ или установите node-fetch:
```bash
npm install node-fetch
```

#### Ошибка подключения к Strapi
Убедитесь что Strapi сервер запущен на порту 1337:
```bash
npm run develop
```

#### Ошибки схемы
Скрипт автоматически добавляет недостающие поля в схемы Strapi. Если возникают ошибки, перезапустите Strapi сервер после первого запуска скрипта.
