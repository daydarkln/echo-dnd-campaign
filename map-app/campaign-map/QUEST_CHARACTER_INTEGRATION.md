# Интеграция персонажей с квестами

## Обзор функциональности

Теперь при редактировании квестов можно добавлять персонажей двумя способами:
1. **Выбрать существующего** персонажа из главной системы персонажей
2. **Создать нового** персонажа прямо в интерфейсе квеста

## Как это работает

### 1. Добавление персонажей в квест

В редакторе квеста:
- Нажмите кнопку **"Добавить персонажей"** в разделе "Связанные NPC"
- Откроется модальное окно `CharacterSelector` с поддержкой множественного выбора и двумя вкладками

### 2. Выбор существующих персонажей (НОВИНКА!)

**Вкладка "Выбрать существующего":**
- Показывает список всех созданных персонажей с чекбоксами
- Отображает информацию: имя, класс, уровень, есть ли полный лист
- **Множественный выбор**: Выберите несколько персонажей одновременно
- Счетчик показывает количество выбранных персонажей
- Кнопка динамически обновляется: "Добавить X в группу"

**Логика при множественном выборе:**
- Для каждого выбранного персонажа проверяется, нет ли его уже в группе квеста
- Создается группа квеста `Квест "[название квеста]"` (если не существует)  
- Каждый новый персонаж добавляется в группу квеста
- ID персонажей добавляются в `relatedNPCs` квеста
- Создаются связи между основными персонажами и персонажами в группе
- **Умная обратная связь**: Сообщение показывает количество добавленных и пропущенных персонажей

### 3. Создание нового персонажа

**Вкладка "Создать нового":**
- Поля: Имя (обязательно), Уровень, Класс
- Нажмите "Создать и добавить в группу"

**Логика при создании:**
- Создается персонаж в главной системе персонажей
- Если указан класс, создается полный лист персонажа (`hasCharacterSheet: true`)
- Если класс не указан, создается базовая информация (`hasCharacterSheet: false`)
- Персонаж сохраняется в localStorage и JSON server
- Персонаж добавляется в группу квеста
- Создается связь между системами

## Синхронизация данных

### Система связей
Связи между персонажами и группами хранятся в `localStorage` под ключом `character-group-mappings`:

```json
[
  {
    "originalCharacterId": "character-123-abc",
    "groupId": "group-456-def", 
    "groupCharacterId": "member-789-ghi"
  }
]
```

### Автоматические проверки
- **Дубликаты**: При добавлении проверяется, нет ли персонажа с таким именем уже в группе
- **Связи**: Существующие персонажи связываются с группами автоматически
- **Обновления**: Изменения в главной системе персонажей можно синхронизировать с группами

## Файлы, затронутые изменениями

### Основные компоненты
- `src/components/QuestEditor.tsx` - Интегрирован CharacterSelector
- `src/components/CharacterSelector.tsx` - Добавлено поле "Класс"

### Новая логика
- `getOrCreateQuestGroup()` - Создание/получение группы квеста
- `createCharacterInMainSystem()` - Создание персонажа в главной системе
- `handleSelectExistingCharacter()` - Обработка выбора существующего персонажа
- `handleCreateNewCharacter()` - Обработка создания нового персонажа

### Хуки и утилиты
- `useCharacters` - Доступ к главной системе персонажей
- `useCharacterGroupSync` - Синхронизация между системами
- `useGroups` - Управление группами

## Преимущества интеграции

1. **Централизация**: Все персонажи в одной системе
2. **Гибкость**: Можно выбирать существующих или создавать новых
3. **Связанность**: Квесты автоматически создают свои группы
4. **Синхронизация**: Изменения можно передавать между системами
5. **Удобство**: Единый интерфейс для управления персонажами

## Поток данных

```
1. Квест → CharacterSelector → Выбор/Создание
2. Персонаж → Главная система персонажей (localStorage + JSON server)
3. Персонаж → Группа квеста (система групп)
4. Связь → character-group-mappings (localStorage)
5. Квест.relatedNPCs ← ID персонажа из группы
```
