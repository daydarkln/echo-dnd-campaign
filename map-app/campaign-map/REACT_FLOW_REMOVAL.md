# Замена ReactFlow на SVG-based решение

## Что изменилось

ReactFlow была полностью удалена из проекта и заменена на собственное SVG-based решение для повышения производительности.

## Новый компонент SvgGraph

Создан новый компонент `SvgGraph.tsx`, который предоставляет аналогичную функциональность:

### Основные возможности:
- ✅ Отображение узлов и рёбер
- ✅ Зум и панорамирование колесиком мыши
- ✅ Интерактивность (клики, ховер)
- ✅ Мини-карта (опционально)
- ✅ Контролы зума
- ✅ Автофит к содержимому
- ✅ Подсветка связанных узлов при ховере
- ✅ Сетка на фоне

### Изменённые компоненты:
- `MapGraph.tsx` - полностью переписан
- `GroupedMindMap.tsx` - полностью переписан
- `PlayerMap.tsx` - полностью переписан  
- `RegionFocusedMap.tsx` - полностью переписан

## Что удалено

- Зависимость `reactflow` из `package.json`
- Все импорты ReactFlow из компонентов
- CSS стили ReactFlow

## Преимущества нового решения

1. **Производительность**: Нет постоянных ререндеров, характерных для ReactFlow
2. **Контроль**: Полный контроль над отрисовкой и интерактивностью
3. **Размер**: Меньший размер bundle без ReactFlow
4. **Настройка**: Легче кастомизировать под специфические нужды

## Управление

### Зум:
- **Колесико мыши**: увеличение/уменьшение
- **Кнопки**: + и - в правом верхнем углу
- **Автофит**: кнопка с иконкой полноэкранного режима

### Панорамирование:
- **Зажать и тащить**: левая кнопка мыши для перемещения по карте

### Интерактивность:
- **Клик по узлу**: открытие деталей локации
- **Клик по ребру**: информация о маршруте
- **Ховер на узел**: подсветка связанных элементов

## Возможные улучшения

В будущем можно добавить:
- Drag & drop для узлов (заготовка уже есть)
- Анимации переходов
- Больше типов узлов
- Кастомные стили для разных типов рёбер

## Запуск

Проект должен работать без дополнительной настройки. Все команды остаются прежними:

```bash
npm start          # Запуск фронтенда
npm run dev:full   # Запуск с API сервером
```

Если возникнут проблемы, выполните:

```bash
npm run clean:install  # Переустановка зависимостей
```
