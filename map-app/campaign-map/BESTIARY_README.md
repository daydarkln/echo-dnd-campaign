# 🐉 Система Бестиария

Полнофункциональная система управления существами для D&D кампании с поддержкой импорта, экспорта и хранения в json-server.

## ✨ Возможности

### 📝 Управление существами
- **Создание** новых существ с нуля
- **Редактирование** существующих существ
- **Просмотр** детальной информации о существах
- **Удаление** существ

### 🔍 Поиск и фильтрация
- Поиск по названию, типу, уровню опасности и тегам
- Фильтрация по типу существа
- Фильтрация по уровню опасности
- Сортировка по различным параметрам

### 📊 Статистика
- Общее количество существ
- Количество типов существ
- Самый популярный тип
- Количество уровней опасности

### 📥 Импорт/Экспорт
- **Импорт** из JSON файлов различных форматов:
  - Open5e API формат
  - 5eTools формат
  - Homebrew формат
  - Собственный формат
- **Экспорт** в JSON
- Валидация импортируемых данных
- Предпросмотр перед импортом

## 🏗️ Структура данных

### Основные поля существа:
```typescript
interface CreatureData {
  // Основная информация
  name: string;
  size: CreatureSize;
  type: CreatureType;
  subtype?: string;
  alignment: CreatureAlignment;
  
  // Боевые характеристики
  armorClass: number;
  hitPoints: number;
  hitDice: string;
  speed: CreatureSpeed;
  
  // Характеристики (СИЛ, ЛОВ, ТЕЛ, ИНТ, МДР, ХАР)
  stats: CreatureStats;
  
  // Уровень опасности и опыт
  challengeRating: string;
  experiencePoints: number;
  
  // Способности, действия, черты
  traits?: CreatureTrait[];
  actions?: CreatureAction[];
  bonusActions?: CreatureAction[];
  reactions?: CreatureAction[];
  
  // Дополнительная информация
  environment?: string[];
  tags?: string[];
  source?: string;
}
```

## 🚀 Использование

### 1. Добавление нового существа
1. Перейти на страницу "Бестиарий" (вкладка с иконкой 🐛)
2. Нажать кнопку "Создать существо"
3. Заполнить форму во вкладках:
   - **Основное**: название, размер, тип, мировоззрение, КД, ХП, УО
   - **Характеристики**: шесть основных характеристик и скорость
   - **Способности**: черты существа
   - **Действия**: действия, бонусные действия, реакции
   - **Дополнительно**: теги, окружение, предыстория
4. Нажать "Сохранить"

### 2. Импорт существ
1. Нажать кнопку "Импорт"
2. Выбрать JSON файл с существами
3. Просмотреть предварительный импорт
4. Подтвердить импорт

### 3. Экспорт бестиария
1. Нажать кнопку "Экспорт"
2. Файл автоматически загрузится в формате JSON

## 🔧 Технические детали

### Хранение данных
- **Основное**: json-server (база данных `db.json`, коллекция `creatures`)
- **Резервное**: localStorage (автоматический fallback)
- **Синхронизация**: автоматическая между сервером и localStorage

### API эндпоинты
- `GET /creatures` - получить все существа
- `POST /creatures` - создать существо
- `PUT /creatures/:id` - обновить существо
- `DELETE /creatures/:id` - удалить существо

### Поддерживаемые форматы импорта
- Массив существ: `[{creature1}, {creature2}]`
- Объект с массивом: `{"monsters": [{creature1}]}`
- Open5e API: `{"results": [{creature1}]}`
- Одно существо: `{creature}`
