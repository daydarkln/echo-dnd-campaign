# Система персонажей и NPC

## Обзор
Добавлена полноценная система управления персонажами игроков и NPC с возможностью создания, редактирования и автоматической генерации листов персонажей.

## Новые страницы и роуты

### 1. Страница персонажей (`/character`)
- **Компонент**: `CharacterPage`
- **Функции**:
  - Отображение списка всех созданных персонажей
  - Кнопка создания нового персонажа
  - Просмотр листа персонажа (если создан)
  - Редактирование персонажа
  - Удаление персонажа
  - Показ статуса наличия листа персонажа

### 2. Страница создания персонажа/NPC (`/character/create`)
- **Компонент**: `CharacterCreationPage`
- **Функции**:
  - Упрощенная форма создания:
    - **Имя персонажа/NPC** - основное поле для любого типа персонажа
    - **Уровень (1-20)** - определяет силу персонажа
  - **Галочка "Создать полный лист персонажа"**:
    - Если включена - создается полный лист с характеристиками, навыками, заклинаниями
    - Если выключена - создается только имя и уровень
  - Подходит как для персонажей игроков, так и для NPC
  - Автоматическое сохранение в JSON server и localStorage
  - Перенаправление на страницу персонажей после создания

### 3. Страница редактирования персонажа (`/character/edit/:id`)
- **Компонент**: `CharacterEditPage`
- **Функции**:
  - Загрузка существующего персонажа
  - Редактирование всех основных характеристик
  - Управление статусом листа персонажа
  - Сохранение изменений

## Навигация
Добавлен новый таб "Персонажи" в главную навигацию приложения между "Карта для игроков" и "Квесты". Таб предназначен для управления как персонажами игроков, так и NPC.

## Техническая реализация

### Новые компоненты и хуки
1. **`useCharacterById`** - хук для работы с персонажами по ID
   - Загрузка персонажа из localStorage и JSON server
   - Полная совместимость с `CharacterSheet` компонентом
   - Автоматическое сохранение изменений

2. **`CharacterCreationPage`** - страница создания персонажей
3. **`CharacterEditPage`** - страница редактирования персонажей
4. **Обновленный `CharacterPage`** - список персонажей с управлением

### Интеграция с существующей системой
- **CharacterSheet** теперь может работать как с дефолтным персонажем, так и с персонажем по ID
- Полная совместимость с существующей системой групп
- Персонажи сохраняются в JSON server (`/characters` endpoint)
- Резервное сохранение в localStorage

### Хранение данных
- **JSON Server**: `/characters` - основное хранилище
- **localStorage**: `dnd-characters-collection` - резервная копия
- Формат данных совместим с существующей системой Character/CharacterData

## Структура данных персонажа

```typescript
interface CharacterFormData {
  name: string;                     // Имя персонажа/NPC
  level: number;                    // Уровень (1-20)
  createCharacterSheet: boolean;    // Создать полный лист
}
```

## Использование

### Создание персонажа/NPC
1. Перейти на вкладку "Персонажи"
2. Нажать "Создать персонажа/NPC"
3. Заполнить упрощенную форму:
   - Ввести имя персонажа или NPC
   - Выбрать уровень (1-20)
   - При необходимости включить создание полного листа
4. Нажать "Создать"

### Редактирование персонажа
1. На странице персонажей нажать "Редактировать" у нужного персонажа
2. Изменить нужные поля
3. Сохранить изменения

### Просмотр листа персонажа
1. На странице персонажей нажать "Лист персонажа" (только если лист создан)
2. Откроется модальное окно с полным листом персонажа

## Интеграция с группами
Созданные персонажи можно добавлять в группы через существующую систему GroupManager. При добавлении персонажа в группу автоматически создается связь между системой групп и системой персонажей.
