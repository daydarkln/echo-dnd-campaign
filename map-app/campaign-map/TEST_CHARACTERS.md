# Тестовые персонажи для проверки

## Исправленная проблема
Теперь в списке персонажей отображаются ВСЕ созданные персонажи, независимо от наличия листа персонажа.

## Что было исправлено:

1. **Логика определения наличия листа**: Изменена с `!== false` на `=== true` для точной проверки
2. **Установка флага при создании**: Добавлена установка `hasCharacterSheet: true` для полных листов
3. **Типизация**: Добавлено поле `hasCharacterSheet?: boolean` в тип `CharacterData`
4. **Улучшенное отображение**: Добавлены теги для различения персонажей с листом и без

## Типы создаваемых персонажей:

### Персонаж с полным листом
- Создается при включенной галочке "Создать полный лист персонажа"
- Имеет `hasCharacterSheet: true`
- Отображается с зеленым тегом "Лист создан"
- Доступна кнопка "Лист персонажа"

### Персонаж без листа (только базовая информация)
- Создается при выключенной галочке
- Имеет `hasCharacterSheet: false`
- Отображается с оранжевым тегом "Только базовая информация"
- Кнопка "Лист персонажа" не отображается

## Примеры для тестирования:

1. **Создать NPC без листа:**
   - Имя: "Торговец Вильям"
   - Уровень: 3
   - Галочка: выключена

2. **Создать персонажа игрока с листом:**
   - Имя: "Эларион Светокрыл"
   - Уровень: 5
   - Галочка: включена

3. **Создать босса без листа:**
   - Имя: "Лорд Тьмы"
   - Уровень: 15
   - Галочка: выключена

Все эти персонажи должны отображаться в списке с соответствующими тегами.
