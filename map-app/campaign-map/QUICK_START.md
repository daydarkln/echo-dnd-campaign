# 🚀 Быстрый старт

## Установка зависимостей

### Вариант 1 (рекомендуемый):
```bash
npm run install:legacy
```

### Вариант 2 (если первый не работает):
```bash
npm run install:force
```

### Вариант 3 (полная очистка):
```bash
npm run clean:install
```

## Запуск приложения

### Полный запуск (API + приложение):
```bash
# 1. Миграция данных и настройка
npm run setup

# 2. Запуск всего проекта
npm run dev:full
```

### Ручной запуск:
```bash
# 1. Миграция данных
npm run migrate

# 2. Запуск API сервера (в одном терминале)
npm run server:start

# 3. Запуск приложения (в другом терминале)
PORT=3003 npm start
```

## Адреса
- **Приложение**: http://localhost:3003
- **API Server**: http://localhost:3001
- **Проверка API**: http://localhost:3001/health

## Возможные проблемы

### Конфликт портов
Если порт 3000 занят, приложение запустится на порту 3003.

### API недоступен
Приложение автоматически переключится на статические файлы.

### Ошибки установки
```bash
# Попробуйте очистить кэш
npm cache clean --force
npm run clean:install
```

## Переключение источников данных
В интерфейсе приложения:
- 🟢 **API Server** - подключение к API
- 📄 **Файлы** - статические JSON файлы
- 🔄 **Обновить** - перезагрузить данные
