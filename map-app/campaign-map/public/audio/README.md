## 🔄 **Новая структура эмбиента**

### **Локации с временем суток (timeOfDay: "auto"):**
- **ambient.day** - Дневной вариант эмбиента (обязательно)
- **ambient.night** - Ночной вариант эмбиента (обязательно)

### **Локации без времени суток (timeOfDay: "none"):**
- **ambient.day** - Единственный вариант эмбиента (обязательно)
- **ambient.night** - Не используется

### **Примеры:**
```json
// Городская локация с временем суток
{
  "ambient": {
    "day": "city-day",
    "night": "city-night",
    "volume": 0.7
  },
  "environment": {
    "timeOfDay": "auto"
  }
}

// Лесная локация с временем суток
{
  "ambient": {
    "day": "forest-day",
    "night": "forest-night",
    "volume": 0.6
  },
  "environment": {
    "timeOfDay": "auto"
  }
}

// Подземная локация без времени суток
{
  "ambient": {
    "day": "library-ambient",
    "volume": 0.5
  },
  "environment": {
    "timeOfDay": "none"
  }
}
```

### **Упрощенная структура:**
- Убрано свойство `layers` для упрощения конфигурации
- Каждая локация имеет только основной ambient звук (дневной/ночной)
- Дополнительные звуковые слои добавляются через эффекты локации
