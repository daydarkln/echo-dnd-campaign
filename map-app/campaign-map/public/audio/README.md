## ⚙️ Настройка и интеграция

### 1. **Размещение файлов**
- Разместите все аудио файлы в соответствующих папках согласно структуре
- Убедитесь, что названия файлов точно соответствуют указанным в конфигурации

### 2. **Конфигурация**
- **audio-config.json** - главный конфиг с глобальными настройками
- **location-audio-bindings.json** - привязки локаций к аудио эффектам

### 3. **Проверка интеграции**
- Откройте разные локации и проверьте автоматическое переключение звуков
- Протестируйте кнопки эффектов в модалках локаций и путей
- Проверьте работу контроллера погоды и времени

## 🔧 Технические требования

### **Форматы и качество**
- **Основной формат**: MP3 (рекомендуется)
- **Альтернативный**: WAV для высокого качества
- **Качество MP3**: 128-320 kbps
- **Частота дискретизации**: 44.1 kHz

### **Длительность и размер**
- **Ambient звуки**: 2-5 минут (зацикленные)
- **Музыка**: 3-7 минут (зацикленные)
- **SFX**: 1-10 секунд
- **Максимальный размер**: 5MB на файл

### **Оптимизация**
- Используйте сжатие без потери качества
- Оптимизируйте длительность для зацикливания
- Убедитесь в совместимости с браузерами
